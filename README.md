# Dati-La-Culla

Dati di lavoro e script per La Culla di Angeletti Daniele (B&B, Ristorante, Rifugio Valgrande).

- `fiscale-2025/` – documentazione fiscale 2025 per lo studio commercialista: checklist, percorsi portali, setup Stripe, protocollo video, struttura archivio.
- `scripts/` – parser fatture elettroniche, export Stripe, fotogrammi da video, scanner PC (`pip install -r scripts/requirements.txt`).
- `tests/` – test eseguibili con `python tests/test_parse_fatture.py`, `python tests/test_stripe_demo.py`, `python tests/test_scan_pc.py`.

I documenti veri restano su Google Drive (`LA CULLA – ARCHIVIO`); qui solo script, template e checklist.
